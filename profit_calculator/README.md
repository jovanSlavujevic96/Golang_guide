# Assignment: Profit Calculator

CLI tool that:
- asks users for `revenue`, `expenses` & `tax rate`
- calculates `earnings before tax` (EBT) & `earnings after tax` (profit)
- caclulates `ratio` (EBT / profit)
- `outputs` EBT, profit and the ratio

CLI should:
- validate users input
  => show error message & exit if invalid input is provided
    - no negative numbers
    - not 0
- store calculated results into a file
